# CampusConnect 🎓

### College Events & Opportunities Portal

CampusConnect is a responsive college web portal designed to bring campus events, opportunities, student clubs, and campus communication together in one place.

Instead of students searching through notice boards, WhatsApp groups, and emails for different opportunities, CampusConnect provides a centralized platform to discover what is happening around the campus.

---

## 🌐 Live Website

🔗 **Live Demo:**  
https://campusconnect-2026-omprakhar.s3-website.ap-south-2.amazonaws.com

The project is currently deployed as a static website using **Amazon S3 Static Website Hosting**.

---

## 📌 Problem Statement

College event and opportunity information is often scattered across:

- Notice boards
- WhatsApp groups
- Emails
- Different club announcements

Because of this, students can miss important events, internships, scholarships, competitions, and club activities.

CampusConnect aims to provide a single centralized platform where students can easily discover campus opportunities.

---

## 💡 Our Solution

CampusConnect provides one responsive web portal for:

- 🎉 Campus Events
- 💼 Opportunities
- 👥 Student Clubs
- 🏫 Campus Information
- 📩 Student Communication

### User Flow

**Visit → Discover Events → Explore Opportunities → Connect with Campus**

---

## ✨ Features

### 🔍 Search & Filter
Students can search events using keywords and filter events based on categories.

### 📅 Event Discovery
Browse upcoming campus events and view relevant event details.

### 💼 Opportunities
Explore:

- Internships
- Scholarships
- Competitions
- Other student opportunities

### 👥 Student Clubs
Discover active campus clubs and their activities.

### 📱 Responsive Design
The website is designed to work across:

- Desktop
- Tablet
- Mobile

### ⚡ JavaScript Interactions
Vanilla JavaScript is used for:

- Search
- Filtering
- Form validation
- Dynamic UI interactions
